# Map Marker

This project demonstrates how to use the Leaflet.js library to create an interactive map with a marker. The marker's position is dynamically updated based on coordinates fetched from an external API.

## Table of Contents
- Introduction
- Features
- Usage
- Technologies
- Contributing
- License

## Introduction
The Map Marker project showcases the integration of Leaflet.js for map rendering and PHP for fetching coordinates from an external API. The map initially centers on Roermond, and the marker updates its position based on the fetched coordinates.

## Features
- **Interactive Map**: Displays a map centered on Roermond using Leaflet.js.
- **Dynamic Marker**: Updates the marker's position based on coordinates fetched from an external API.
- **Responsive Design**: Ensures the map is displayed correctly on various screen sizes.

## Usage
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/map-marker.git
    ```
2. Navigate to the project directory:
    ```bash
    cd map-marker
    ```
3. Ensure you have a local server running (e.g., XAMPP, WAMP, MAMP).
4. Place the project files in the server's root directory (e.g., `htdocs` for XAMPP).
5. Open the `index.html` file in your browser to view the map.

## Technologies
- **HTML**: For structuring the web page.
- **CSS**: For styling the map container.
- **JavaScript**: For integrating Leaflet.js and handling map interactions.
- **PHP**: For fetching coordinates from an external API.
